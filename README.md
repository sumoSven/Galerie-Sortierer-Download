# Galerie-Sortierer – Testversion

**Deine Screenshots, endlich sortiert.** Die App liest den Text in deinen Screenshots, schlägt
passende Ordner vor und lässt dich aufräumen wie bei Tinder: **nach links wischen = löschen,
nach rechts = einsortieren.** Alles passiert auf deinem Handy, ohne Internet.

## ⬇️ Herunterladen

**[Galerie-Sortierer.apk herunterladen](https://github.com/sumoSven/Galerie-Sortierer-Download/releases/latest/download/Galerie-Sortierer.apk)**
(ca. 44 MB, für Android 11 oder neuer)

## Installieren

1. Den Link oben **auf dem Handy** öffnen und die Datei herunterladen.
2. Die heruntergeladene Datei antippen.
3. Android fragt, ob dein Browser bzw. deine Dateien-App **„unbekannte Apps installieren“** darf –
   einmal erlauben, dann zurück und **Installieren** tippen.
4. Falls **Google Play Protect** warnt: Die App kommt nicht aus dem Play Store, deshalb kennt Google
   sie nicht. *Weitere Details → Trotzdem installieren.*

**Neue Version?** Einfach wieder über den Link herunterladen und installieren – das ist ein Update,
deine Notizen bleiben erhalten.

## Gut zu wissen

- Das ist eine **Demo zum Testen**. Probier sie zuerst mit unwichtigen Screenshots aus.
- Die App fragt vor jeder Änderung nach. Gelöschtes liegt **30 Tage im Papierkorb** deiner Galerie,
  und beim Wischen holt „↶“ den letzten Schritt zurück.
- **Datenschutz:** Die App hat keine Internet-Berechtigung. Bilder, erkannter Text und Notizen
  bleiben auf deinem Handy.
- Beim ersten Start erklärt eine kurze Anleitung alles. Später findest du sie über das „?“.
